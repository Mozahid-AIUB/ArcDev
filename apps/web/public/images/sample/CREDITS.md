# Brand source files

The CC0 stock placeholders formerly in this folder have been removed now that the site
uses ArcDev's real project photography (see `public/images/projects/`).

`mainlogo.png` and `latterhead.png` are the client's original logo and letterhead files,
kept here as source references. The processed versions used on the site live in
`public/images/brand/` (`logo-mark.png`, `letterhead.png`) and `apps/web/src/app/`
(`icon.png`, `apple-icon.png`, generated from the logo mark).
